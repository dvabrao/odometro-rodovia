# Odômetro Rodovia Pro

App Android para levantamento de patologias rodoviárias em campo.

**DVAbrao Serviços Ltda**

## Como gerar o APK

1. Faça push para a branch `main`
2. O GitHub Actions compila automaticamente
3. Baixe o APK em **Releases** → `OdometroRodovia.apk`

## Funcionalidades

- Rastreamento GPS com rota em KML
- Marcação de patologias com fotos e descrição livre
- GPS continua gravando com a tela desligada (foreground service)
- Tela permanece ligada enquanto o app está aberto
- Exportação em KML, KMZ e PDF
- Complementar rotas existentes via importação de KML
